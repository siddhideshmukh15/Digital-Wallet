💳 Digital Wallet

A simple Digital Wallet project built using Python.
It allows users to manage their wallet balance through basic operations like adding money, spending money, and checking the current balance.

🚀 Features

- 💰 Add money to the wallet
- 💸 Spend money from the wallet
- 💳 Check wallet balance
- 📋 Simple menu-driven interface
- ⚠️ Prevents spending more than the available balance

🛠️ Concepts Used

- Python variables
- "input()" and "print()"
- Conditional statements
- "while" loops
- Functions
- Basic arithmetic operations

▶️ How to Run

1. Make sure Python is installed.
2. Download or clone this repository.
3. Open the project folder in VS Code or terminal.
4. Run:

python digital_wallet.py

🎯 Learning Outcome

This project helped me practice functions, loops, conditions, user input, and basic financial calculations in Python.
